LEARNIX STUDENT SKILLS & CAREER READINESS UPDATE

What's improved:
- Student Success Score now includes a fuller weighted breakdown, contribution points, interpretation, strengths, attention areas, and practical next steps.
- Student Segmentation explains the student's current support focus, why each segment exists, suggested actions, and the indicator snapshot. It is guidance, not a ranking.
- Placement Readiness includes separate aptitude, coding, and mock interview summaries, advice based on scores, editable inputs, and practical weekly goals.
- Skills now supports adding/updating/removing technical and soft skills, proficiency levels from Beginner to Expert, and evidence notes.
- Career-based skill gap checklist and learning roadmap for Full Stack Developer, Software Engineer, AI/Data Analyst, and Cybersecurity Analyst.
- Certifications and Projects portfolio supports adding/removing items, descriptions, demonstrated skills, and optional links.
- Data is saved in browser local storage per signed-in demo student.

Important:
- This version stores the added skill and portfolio information in this browser. It does not automatically sync across devices or to an institutional database.
- Success score weights and segment rules are illustrative prototype rules, not official KPMG weights and not validated predictions.
- Scores are self-entered unless supported by a connected assessment source.
- Open index.html using the project's usual login flow. For a multi-user production deployment, connect these records to a properly secured backend with role-based access and validation.
