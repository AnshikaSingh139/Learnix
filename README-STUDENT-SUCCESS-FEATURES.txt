LEARNIX — STUDENT SUCCESS FEATURES UPDATE

New student portal sections
1. Student Success Score
   - Weighted 0–100 score calculated from academic performance, attendance, assignment/LMS completion, engagement, placement readiness, and skills.
   - Explainable breakdown shows each indicator, its value, weight, and contribution.
   - Shows review reasons and a suggested next action.

2. Student Segmentation
   - Rule-based groups update when the student's data changes.
   - Includes academic support, placement preparation, low engagement, high-performing, and balanced progress groups.

3. Placement Readiness
   - Editable aptitude, coding assessment, and mock interview scores (0–100).
   - Placement readiness average recalculates after saving.

4. Skills
   - Editable technical and soft skills ratings, plus engagement score.
   - Overall skills average and Success Score update after saving.

5. Feedback
   - Submit feedback category, 1–5 rating, and message.
   - Feedback history is shown and individual entries can be deleted.

New teacher portal sections
- Student Success Score: class sample table with scores, placement readiness, and explainable review factors.
- Student Segmentation: sample student cohorts and recommended support actions.

How to use
- Extract the ZIP while keeping the LEARNIX folder together.
- Open index.html and sign in using the project's existing demo login flow.
- Student portal: use the left menu to open Student Success Score, Student Segmentation, Placement readiness, Skills, and Feedback.
- Teacher portal: use Student Success Score and Student Segmentation in the left menu.

Data and scoring notes
- Student editable values and feedback are saved in browser localStorage, scoped to the signed-in student account. They are not automatically shared with the teacher portal or synced to an institution database in this prototype.
- Teacher analytics use clearly labelled sample student records in the existing demo workspace.
- Success Score uses proposed prototype weights: academic 30%, attendance 20%, LMS/assignment completion 15%, engagement 10%, placement 15%, and skills 10%. These are not prescribed by KPMG and have not been validated as a predictive model.
- Risk and segment rules are intended to guide supportive review, not to make automatic decisions about students.
